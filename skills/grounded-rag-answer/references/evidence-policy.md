# Evidence decision policy

Use this hierarchy when evidence quality is ambiguous:

1. Prefer direct text that addresses the same party, subject, time period, and condition as the claim.
2. Treat a source as partial when it supports only part of a compound claim or omits a material qualifier.
3. Report conflicting sources explicitly. Do not silently choose one unless authority, version, or effective date resolves the conflict.
4. Treat “the documents do not require X” as a negative claim. Support it only when the searched corpus and relevant sections are sufficiently complete; otherwise say that no requirement was found in the retrieved material.
5. Do not use retrieval rank as proof. Rank determines review order, while source text determines support.

Classify each material claim as:

- `supported`: direct or clearly entailed by cited text.
- `partial`: some elements are supported but a qualifier, scope, or premise is missing.
- `conflicted`: retrieved sources materially disagree.
- `unsupported`: no retrieved source supports the claim.
